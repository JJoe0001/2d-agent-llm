# 审稿人 2 意见 3：参数来源与扩展敏感性复算

## 研究问题与证据边界

本次复算使用 2026 年 10 月公开仓库中的代码，检查参数改变是否影响初始判维、几何候选切片、断键分量、结构匹配及 CHGNet 计算资格。它是对**当前实现**的新计算，不能当作 2026 年 3 月生产运行的重建。原始生产配置、完整父体 CIF 快照和客户端工具调用轨迹没有留存。所有结论须按其实际计算阶段陈述；下述结果均不是 DFT 稳定性或全体 73,105 个候选对参数稳健性的证明。

参数来源逐项列于 [PARAMETER_AUDIT.md](PARAMETER_AUDIT.md)。XCP 势形式和元素对参数来自 Barnowsky 等人的原论文及 FINDSLAB v1.1 归档；StructureMatcher 的 0.2／0.3／5° 与[官方类文档](https://pymatgen.org/pymatgen.core.html#pymatgen.core.structure_matcher.StructureMatcher)列出的默认值一致；几何网格、平滑宽度、间隙阈值、前三面选择、BONDDEL 分组容差和原子数上限均是本项目实现设置，缺乏足以将它们归为“逐项照搬文献”或“全局最优”的证据。高斯核宽度在三维密度网格中设置，另有沿晶面投影的一维 d_smooth=0.1，两者不能混称。所谓“切割分数截止值”在当前代码中只是评分大于零，并没有另一个非零的经验截止常数。

## 固定样本与方法

1. **200 个父体分层面板。** 以已有的三路线母体命中标签划分为 000–111 共八组，每组用固定种子 20261007 选取 25 个可读取且不超过 80 原子的父体，样本量为 200；中位原子数 16，范围 2–80。这个上限用于控制复算开销，使样本偏向中小晶胞。父体 ID 和原子数见 parameter_sensitivity_panel_200.csv，脚本 make_parameter_panel.py 可复现选取规则。
2. **初始判维。** 对上述 200 个父体比较默认 δ=[1.2,1.3,1.4]、仅 1.2、仅 1.4、窄扫描 [1.2,1.3] 和宽扫描 [1.1,1.2,1.3,1.4,1.5]。当前判维实现选择扫描中最低的平移秩，并在并列时比较覆盖率，故增加扫描点不一定提高 rank-2 数。
3. **几何切片。** 对八组各 25 个父体的 200 面板逐项改变 gap_level、dmin 和三维网格，并在先前固定的 48 父体面板上增加高斯核宽度变体。除所改变的参数外，均取评分最高的三个晶面，并按 [1.2,1.3,1.1,1.4,1.5] 的顺序尝试提取 rank-2 切片。每个父体内部以 StructureMatcher 默认容差去重，再把不同设置的父体关联候选集合逐一匹配。候选集合交并比以匹配后的交集数量除以并集数量计算，仅针对至少有一个候选的父体。此实验强制运行几何分支，用于隔离其参数作用；它并不模拟完整路由判定。
4. **断键阳性富集面板。** 从本地留存的断键产物文件名所对应的 9,393 个母体 ID 中，以同一固定种子抽取 150 个 ID，再在有父体 CIF、最多 40 原子的记录中取最小的 8 个；另加入已作为逐步实例的 mp-1376393。该样本刻意富集先前产生过断键切片的父体，不能用成功比例估计总体产率。对 9 个父体分别改变 0.03 eV 分组容差和 −2.0 eV 扫描下限，一次只改一个值。历史产物只用于选样，所有结果由当前代码重新计算。
5. **去重容差压力测试。** 从已发布的去重后 CIF 归档中，按候选化学式计数选取最大且至少有十条记录的 50 组，每组固定种子抽取 10 条，共 500 条。比较 0.1／0.2／3°、0.2／0.3／5°、0.3／0.4／7° 三组 StructureMatcher 容差，保持原胞归约及不搜索超胞。因输入已经按基线去重，这只能测试较宽松容差是否继续合并，不能测出较严格容差能恢复多少当时已删除的记录。
6. **500 原子上限。** 从 73,105 条候选主表审计原子数、现有松弛标记和跳过状态。改变上限后的实际 CHGNet 结果没有重算，因此仅能统计计算资格变化。

## 已完成结果

### 初始判维：200 个父体

| δ 设置 | rank-2 父体 | 与默认平移秩相同 |
|---|---:|---:|
| 默认 [1.2,1.3,1.4] | 79/200 | 200/200 |
| 仅 1.2 | 35/200 | 125/200 |
| 仅 1.4 | 77/200 | 197/200 |
| 窄扫描 [1.2,1.3] | 52/200 | 149/200 |
| 宽扫描 [1.1,1.2,1.3,1.4,1.5] | 70/200 | 142/200 |

这表明成键因子扫描范围会明显影响几何／断键分支的入口分类。尚未在这些变化后把所有父体继续运行到最终候选库。

### 几何分支：200 个父体的真实切片

| 相对基线的单项变动 | 有 rank-2 切片的父体 | 父体内去重后候选总数 | 与基线候选集合相同的父体 | 父体关联候选交并比 |
|---|---:|---:|---:|---:|
| 基线：gap 0.75、dmin 1.8 Å、网格 32³ | 178/200 | 398 | 200/200 | 1.000 |
| gap 0.65 | 178/200 | 395 | 132/200 | 0.669 |
| gap 0.85 | 177/200 | 396 | 142/200 | 0.711 |

| 网格 24³ | 180/200 | 398 | 94/200 | 0.488 |
| 网格 48³ | 178/200 | 393 | 114/200 | 0.551 |

全部 1,400 次父体与参数组合均完成，没有顶层 Python 异常。虽然候选总数在各组间接近，部分参数变化明显改变了最终提取出的切片身份。该实验与前述初始判维实验使用同一批父体，却强制执行几何分支以隔离几何参数作用；两张表不能简单串接为完整路线产率。

### BONDDEL：9 个阳性富集父体

| 设置 | 找到 rank-2 分量 | 状态及分量原子索引集合与基线相同 |
|---|---:|---:|
| 基线：分组 0.03 eV、扫描下限 −2.0 eV | 7/9 | 9/9 |
| 分组 0.02 eV | 7/9 | 7/9 |
| 分组 0.05 eV | 6/9 | 8/9 |
| 扫描下限 −1.5 eV | 5/9 | 7/9 |
| 扫描下限 −2.5 eV | 7/9 | 9/9 |

把分组容差缩至 0.02 eV 时，mp-1104843 与 mp-1209536 虽仍成功，所得分量发生改变；放宽至 0.05 eV 时，mp-28545 从成功变为未找到二维分量。扫描下限提高到 −1.5 eV 时，mp-1209536 与 mp-1376393 失去基线的 rank-2 结果。这个有意选取的阳性面板说明断键参数可影响输出；它不能给出总体变化率。此前按八种路线标签选取小晶胞的 17 父体面板仍单独保留，基线仅有 2/17 成功。

### 去重与原子数上限

500 个已去重切片在基线 0.2／0.3／5° 和更严格的 0.1／0.2／3° 设置下均保留 500 条；较宽松的 0.3／0.4／7° 则留下 484 条、额外合并 16 条。由于不是去重前全集，不能据此推算 76,852 条输入在新容差下会剩多少。

73,105 条候选中有 169 条超过 500 原子，现均记为 Skipped (Too Large)。若把上限降为 400 原子，原先 401–500 原子的 68 条会失去计算资格，其中 38 条在现有表中有松弛成功标记；若提高到 600 原子，501–600 原子的 32 条会取得计算资格，但其实际松弛结局未知。上限是资源保护条件，不是物理稳定性阈值。

## 可复算文件与尚缺环节

在仓库根目录、安装科学计算依赖并准备好父体 CIF 目录后，主要复算命令如下。将 PARENT_DIR 换成包含以 MP ID 命名 CIF 的目录；本地运行所用目录的文件哈希记录在结果 JSON 中。

```bash
python scripts/make_parameter_panel.py PARENT_DIR
python scripts/dimensionality_delta_sensitivity.py PARENT_DIR
python scripts/planar_candidate_sensitivity.py PARENT_DIR --panel data/computed_results/parameter_sensitivity_panel_200.csv --output data/computed_results/planar_candidate_sensitivity_200.json
python scripts/planar_candidate_sensitivity.py PARENT_DIR --variants baseline,gauss_0p35,gauss_0p65 --output data/computed_results/gaussian_width_candidate_sensitivity_48.json
python scripts/bonddel_sensitivity.py PARENT_DIR --panel data/computed_results/bonddel_archived_positive_panel.csv --parents-per-signature 9 --workers 4 --timeout-seconds 60 --output data/computed_results/bonddel_archived_positive_sensitivity.json
python scripts/dedup_tolerance_sensitivity.py
python scripts/atom_cap_audit.py
```

| 内容 | 脚本 | 结果 |
|---|---|---|
| 200 父体选样 | scripts/make_parameter_panel.py | data/computed_results/parameter_sensitivity_panel_200.csv |
| 初始判维 δ | scripts/dimensionality_delta_sensitivity.py | data/computed_results/dimensionality_delta_sensitivity.json |
| 200 父体几何切片 | scripts/planar_candidate_sensitivity.py | data/computed_results/planar_candidate_sensitivity_200.json |
| 48 父体几何切片复核 | 同上 | data/computed_results/planar_candidate_sensitivity.json |
| 高斯宽度 | 同上 | data/computed_results/gaussian_width_candidate_sensitivity_48.json |
| 断键参数 | scripts/bonddel_sensitivity.py | data/computed_results/bonddel_archived_positive_sensitivity.json |
| 去重容差 | scripts/dedup_tolerance_sensitivity.py | data/computed_results/dedup_tolerance_sensitivity.json |
| 500 原子上限 | scripts/atom_cap_audit.py | data/computed_results/atom_cap_audit.json |

结果文件保留面板、参数、逐父体状态、CIF 或输入文件哈希以及耗时。复算需安装仓库科学依赖，并取得所列 MP ID 对应的父体 CIF。当前 GitHub 没有历史父体 CIF 全量快照，重新从 MP 下载同 ID 结构不保证文件字节相同。
