# BONDDEL 断键参数敏感性：代码阶段复算

本次复算只检验公开版本 BONDDEL 图搜索的输出，不包含后续切片生成、跨路线去重、CHGNet 松弛或 VASP 验证。因此下表不能用作最终候选集稳健性或材料稳定性的证据。

## 样本与设置

- 从既有 48 个父体的几何敏感性面板中，按三条路线的 8 种命中组合分层，每层选原子数最少的 2 个父体，共 16 个。该取样偏向小晶胞，**基线仅 1 个产生二维分量**。
- 另外加入已复现断键路径的 `mp-1376393`（Zn₂Cr₂O₅）作阳性对照；不把它说成随机抽样。
- 基线：键能分组容差 0.03 eV，能级扫描下限 −2.0 eV。单因素变体为容差 0.02、0.05 eV，以及下限 −1.5、−2.5 eV。每个父体每组设置最多运行 60 秒。使用同一份 `POTDATA_morse_yukawa_2025` 势参数文件。
- “一致”要求运行状态及最终连通分量的原子索引集合均与该父体基线相同。对未找到二维分量的 15 个分层样本，一致仅表示它们仍未找到二维分量。

| 设置 | 找到二维分量的父体 | 与基线状态及分量一致 | 单任务耗时之和 |
|---|---:|---:|---:|
| 基线 0.03 eV / −2.0 eV | 2/17 | 17/17 | 200.8 s |
| 分组容差 0.02 eV | 2/17 | 17/17 | 229.4 s |
| 分组容差 0.05 eV | 2/17 | 17/17 | 149.5 s |
| 扫描下限 −1.5 eV | 1/17 | 16/17 | 199.3 s |
| 扫描下限 −2.5 eV | 2/17 | 17/17 | 201.9 s |

表中耗时为各任务耗时的**总和**，不是四进程并行执行的墙钟时间，不能直接解释为参数改变导致的速度增减。各组均未出现报错或超时。阳性对照在基线下首次于 −1.557499 eV 找到二维分量；当扫描下限升至 −1.5 eV 时，这一能级不再被检查，该对照没有找到二维分量。其余四组设置中，对照的分量原子索引集合相同。

## 复算与边界

脚本为 `scripts/bonddel_sensitivity.py`。分层面板使用仓库中的 `data/computed_results/planar_sensitivity_panel.csv`；阳性对照面板为 `data/computed_results/bonddel_positive_control_panel.csv`。逐父体的状态、阈值、原子索引和耗时分别保存在 `data/computed_results/bonddel_sensitivity.json` 与 `bonddel_positive_control.json`，其中还记录面板和势参数 SHA-256。

在安装仓库依赖并取得原始 MP 父体 CIF 后，可分别运行：

```bash
python scripts/bonddel_sensitivity.py /path/to/parent_cifs --workers 4 --timeout-seconds 60
python scripts/bonddel_sensitivity.py /path/to/parent_cifs --panel data/computed_results/bonddel_positive_control_panel.csv --parents-per-signature 1 --workers 1 --timeout-seconds 60 --output data/computed_results/bonddel_positive_control.json
```

该面板的基线阳性样本太少，无法推断总体成功率、最终候选集合交并比或参数最优值。完整回应审稿意见仍需要对更大、事先固定且涵盖成功与失败案例的父体面板进行全流程重跑，单独改变结构去重容差，并报告候选集合与 CHGNet 后形貌的变化。上述复算不替代 DFT 剥离能和二维热力学或动力学稳定性计算。
